# gallery-site

오늘전시 — 친구들과 공유하는 서울 전시 정보 사이트. (사이트 이름은 `lib/site.mjs`의 `SITE_NAME`)

## 수집 범위

- 서울의 국공립·사립미술관 및 개인 갤러리 전시
- 한국문화정보원 API를 기본 정보원으로 사용
- API에서 빠진 민간 전시는 공식 미술관·갤러리 안내를 확인해 별도 보완
- 확인된 전시만 게시하며, 출처와 확인 시점을 표시

## 화면 구성

- 포스터 중심 전시 목록: 전시명, 장소, 기간, 관람료
- 진행 중 / 예정 / 곧 종료, 지역, 무료 여부로 탐색
- 상세 안내 및 공식 링크, 위치 확인, 친구에게 링크 공유
- 이미지 미제공 시 명확한 대체 표시
- 모바일에서도 사용할 수 있는 반응형 화면

## 기본 데이터 소스

한국문화정보원_한눈에보는문화정보조회서비스

- 공식 안내: https://www.data.go.kr/data/15138937/openapi.do
- Base URL: https://apis.data.go.kr/B553457/cultureinfo
- 응답 형식: XML
- 승인된 기능: /period2, /area2, /detail2, /livelihood2, /realm2
- 신청 화면의 일일 트래픽: 기능별 10,000

## 연동 구현 전 확인 항목

현재 공유된 정보는 기본 URL 및 기능 목록이다. 요청 파라미터와 응답 필드 명세는 아직 확인하지 않았다.

1. /area2 또는 /realm2의 요청변수 표와 응답변수 표 확인
2. 서울 지역값 및 전시 분야값 확인
3. /detail2의 식별자와 상세 응답 확인
4. 페이지 처리 및 기간 검색 조건 확인
5. 인증키 설정 후 실제 응답으로 XML 파싱과 수집 범위 검증

## 인증키 관리

서버 환경변수 이름은 CULTURE_API_KEY로 정한다. 실제 인증키는 저장소 또는 브라우저 코드에 넣지 않는다. 화면은 서버가 정리한 전시 데이터만 받는다.

## 데이터 품질

공공 API가 서울의 모든 민간 전시를 포함한다고 가정하지 않는다. 원문 링크, 종료일, 서울 소재 여부를 확인하고 중복 전시를 합친다. 정보가 없는 관람료나 휴관일은 추정하지 않는다.

## 현재 상태

기획 및 API 연결 요구사항을 정리한 초기 저장소. 실행 가능한 사이트 및 배포는 아직 완료되지 않았다.

## 페이지 렌더링과 검색 노출 (2026-10-26)

검색엔진·AI 크롤러·카카오톡 미리보기가 JS 없이도 내용을 읽도록, 페이지는 서버(`api/site.js`)가 완성된 HTML로 내려준다. 브라우저 JS(`app.js`, `detail.js`)는 그 위에서 필터·정렬·위치만 붙인다.

| 주소 | 내용 |
|---|---|
| `/` | 진행 중 전시 목록, `WebSite`·`ItemList` JSON-LD |
| `/exhibitions/{seq}` | 전시 상세, `ExhibitionEvent`·`BreadcrumbList` JSON-LD. 끝난 전시는 404 |
| `/sitemap.xml` | 진행 중 전시 전체, lastmod = 수집일 |
| `/robots.txt` | 프로덕션은 전체 허용, 프리뷰는 전체 차단 |
| `/detail?seq=` | 예전 주소. `/exhibitions/{seq}`로 영구 이동 |

- 화면 표기 코드는 `public/common.js` 한 곳에 있고 서버와 브라우저가 같이 쓴다.
- 커스텀 도메인을 붙이면 환경변수 `SITE_URL`(예: `https://example.kr`)로 canonical·sitemap 주소를 고정한다.
- 로컬 미리보기: `npm run dev` (배포 사본 데이터). 실데이터로 보려면 `DATA_URL=<운영 주소>/api/exhibitions npm run dev`.

## 모아 보기·전시장·아카이브·내 전시 (2026-10-27)

| 주소 | 내용 |
|---|---|
| `/ending-soon` | 일주일 안에 끝나는 전시 |
| `/free` | 무료 전시 |
| `/gu/{구}` | 구별 전시 (진행 중 전시가 있는 구만) |
| `/venues/{장소 id}` | 전시장: 지금 하는 전시 + 지난 전시 |
| `/archive` | 끝난 전시를 끝난 달별로 |
| `/me` | 내 전시: 가볼래요·다녀왔어요 기록 (브라우저 localStorage, 색인 안 함) |

- **아카이브**: `api/collect.js`가 매일 수집할 때 직전 수집본과 새 수집본을 Blob `archive.json`에 합친다(`lib/archive.mjs`). 끝난 전시 상세는 404 대신 '종료된 전시'로 남는다.
- **내 전시**: `public/mine.js`(저장), `public/mine-ui.js`(카드 버튼·상세 패널), `public/me.js`(내 전시 페이지). 저장할 때 전시 스냅샷을 같이 남겨, 전시가 끝나도 기록이 보인다. 파일 내보내기·불러오기로 기기 이동.
